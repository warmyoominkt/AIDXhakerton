# E2E Test

> 다른 사람이 그대로 재현할 수 있게 쓴다.
> 결과: PASS / FAIL / SKIP · 실행하지 않은 시험은 결과 칸을 비우지 말고 "미실행"으로 쓴다.

## 1. 실행 환경

| 항목 | 값 |
|---|---|
| OS / 브라우저 | |
| 런타임 버전 | |
| 시험 도구 | [예: Vitest, Playwright] |
| 데이터 상태 | [초기화 방법 / 시드 데이터] |

## 2. 실행 방법

```bash
# 단위 시험
[명령]
# E2E 시험
[명령]
# 리포트 확인
[명령 또는 경로]
```

## 3. 시험 케이스

| TC | 유형 | 연결 REQ / AC / FLOW | 시나리오 | 예상 결과 |
|---|---|---|---|---|
| TC-01 | 정상 | REQ-01 / AC-01 / FLOW-01 | | |
| TC-02 | 오류 | | | |
| TC-03 | 권한 경계 | | | |
| TC-04 | 저장 후 재조회 | | | |

|---|---|---|---|---|---|
